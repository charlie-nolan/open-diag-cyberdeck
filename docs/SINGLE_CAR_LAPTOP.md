# One car, any laptop

The step-by-step guide for running this app on an ordinary laptop (one car's database, a USB OBD cable, and answers
from a local model, your desktop, an API key or a subscription you're signed into) has moved to its own repo:

**[open-diag-laptop](https://github.com/charlie-nolan/open-diag-laptop)**: the guide, setup script, ready-made
settings files, test results and the simulation harness. All the code it uses is here, in open-diag-cyberdeck.

How long building one car's database takes: [BUILD_ESTIMATES.md](BUILD_ESTIMATES.md).
