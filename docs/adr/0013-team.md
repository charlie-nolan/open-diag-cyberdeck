# ADR-0013: Team mode (team/, teamdeck/)

Status: Accepted (recorded 2026-11-20)

## Context

These decisions were written as code comments next to the code they explain. Comments are banned
(ADR-0001), so they are kept here. Each entry names the file and the function or class it applies to;
search the file for that name. When the code changes, update or remove the entry in the same change.

## Decisions

### `team/kb_mcp.py`

- `KB.__init__`: CPU query embedder (float32): the GPU belongs to Home mode and the build jobs.
- `fetch_page`: Read with our own user agent (urllib's default one is refused by some sites, which reads as "disallow all")

### `team/replay.py`

- One per make outside Subaru, then Subaru spread over models, years and code families.
- `run`: The local baseline runs once per case (it never uses the web)

### `team/run.py`

- `final`: Home is checked against what Home was given (case + pack), as the app does; Team against everything.
