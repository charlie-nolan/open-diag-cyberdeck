# ADR-0009: GM / Chevrolet pipeline and live data (makes/)

Status: Accepted (recorded 2026-11-20)

## Context

These decisions were written as code comments next to the code they explain. Comments are banned
(ADR-0001), so they are kept here. Each entry names the file and the function or class it applies to;
search the file for that name. When the code changes, update or remove the entry in the same change.

## Decisions

### `makes/gm_live.py`

- Default (functional) request headers, so a Mode 22 header can be switched back without a reset.
- `compile_equation.f`: Reject bad equations at load time, not mid-drive.

### `makes/make_pipeline.py`

- `step_vin`: A WMI shared by two makes is left to the built-in table manual pick.
- `step_kb`: Fresh build each time (CHARM re-runs don't drop stale vehicle rows)
- `dtc_names`: Codes the CHARM page doesn't name: PCMHammer's GM code list (GPL-3), only for codes already in this DB.
- `forum_fetch`: Archive.org refuses connections for a while when pulled too fast: 3 s apart (as for Ultimate Subaru), few quick retries, and stop this forum after 5 refusals in a row instead of retrying forever.
- `step_gm_pids.add`: Another source agrees on this reading: note it, keep the first.
- `step_gm_pids.add`: Another source reads this PID differently: keep the first, flag it.
- `step_gm_pids.add`: Same source, same PID, different conversion = PCMHammer's alternates (e.g. sensor variants): keep each.
